## Slide 3 — Ejercicio 1: Generar un servicio completo

```bash
cd mi-proyecto
claude

> Crea un servicio ProductoService.cs con:
  - CRUD completo para productos en Cosmos DB
  - DTOs con records: ProductoDto, CrearProductoDto, ActualizarProductoDto
  - Validación con FluentValidation
  - Logging estructurado
  - Cancellation tokens
  - Tests unitarios con xUnit + Moq + FluentAssertions

# Verificar:
dotnet build   # ¿Compila sin errores?
dotnet test    # ¿Tests pasan?
```

Evaluad: ¿El código generado sigue las convenciones del proyecto? ¿Los tests cubren los edge cases? ¿El logging es útil?

## Slide 6 — Ejercicio 4: Análisis de error

```bash

     at System.Linq.ThrowHelper.ThrowNoElementsException()
     at System.Linq.Enumerable.First[TSource](IEnumerable`1 source)
     at VentasApi.Services.PedidoService.GetPedidoAsync(String id)
```

## Slide 12 — Ejercicio 7: Comparativa de prompts

Probad el MISMO task con diferentes niveles de detalle:

```bash
# Prompt 1 (vago):
> Crea un servicio de pedidos

# Prompt 2 (medio):
> Crea un PedidoService con CRUD para Cosmos DB en .NET 8

# Prompt 3 (detallado):
> Crea un PedidoService.cs para .NET 8 con Cosmos DB:
  - Constructor: CosmosClient + ILogger<PedidoService>
  - GetByIdAsync(string id, CancellationToken ct): Pedido?
  - CreateAsync(CrearPedidoDto dto, CancellationToken ct): Pedido
  - ListByClienteAsync(string clienteId, int page, int size, CancellationToken ct): PagedResult<Pedido>
  - Partition key: /clienteId
  - Manejo de CosmosException (404 → null, 429 → retry)
  - Records para DTOs
```

Comparad los 3 resultados. ¿Cuánto impacta el nivel de detalle?
